Über das Spiel

Brainoku ist ein modernes Sudoku-Spiel mit täglichen Levels, Bestzeiten-Jagd und einem cleveren Tipp-System. Jedes Level ist für alle Spieler weltweit identisch — vergleich dich mit anderen oder schlag deinen eigenen Rekord. Das Spiel läuft komplett im Browser, ist aber so gebaut, dass es sich auf dem Handy wie eine native App anfühlt.

Auf dem Handy

Brainoku ist eine Progressive Web App. Das heißt: keine Installation aus dem Store nötig — du kannst sie direkt aus dem Browser zum Home-Bildschirm hinzufügen und sie läuft wie eine richtige App.

iPhone (Safari)

  1. brainoku.vercel.app öffnen
  2. Teilen-Button (Pfeil-hoch) tippen
  3. „Zum Home-Bildschirm" wählen

Android (Chrome)

  1. Seite öffnen
  2. Drei-Punkte-Menü → „App installieren"

Tech

Brainoku ist eine reine Web-App in HTML, CSS und JavaScript — kein Framework. Sounds werden über die Web Audio API live synthetisiert (kein Asset-Bundle), Themes bestehen aus CSS-Custom-Properties + SVG-Patterns als Data-URIs. Optionale Cloud-Synchronisation via Supabase. Hosted auf Vercel.
